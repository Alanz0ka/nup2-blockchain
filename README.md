# NUP2: Blockchain e Arquiteturas Descentralizadas

Material do seminário NUP2 (Web3, contratos inteligentes, DApps, consenso, quando não usar blockchain e trade-offs).

- `NUP2 - Blockchain e Arquiteturas Descentralizadas.pptx` e `.pdf`: 23 slides (o pptx tem notas de fala).
- `DIVISAO-TAREFAS.md`: requisitos, divisão em três partes e checklist.
- `PERGUNTAS-PROVAVEIS.md`: perguntas e respostas curtas para a arguição.
- `demo-hardhat/`: contrato de votação em rede local (Hardhat 3), testes, DApp de uma página e benchmark. Ver o README da pasta.
- `demo-mini-blockchain/`: mini-blockchain em Node.js, sem dependências.
- `slides/gerar-slides.js`: gerador do deck (pptxgenjs).
